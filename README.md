# keypress-tracker

Локальный трекер нажатий клавиш для Windows: фоновый перехват клавиатуры,
плавающий счётчик поверх окон и окно статистики с heatmap клавиатуры.

Работает полностью офлайн, без внешних зависимостей — только стандартная
библиотека Python (`ctypes` + `tkinter`). Данные не покидают компьютер.

## Возможности

- Глобальный перехват клавиш через `WH_KEYBOARD_LL` (работает в любом
  приложении, даже когда окно трекера не в фокусе).
- Плавающий полупрозрачный оверлей: всего нажатий, текущая раскладка
  и скорость (клавиш в минуту). Перетаскивается мышью, позиция запоминается.
- Счётчики раздельные по раскладкам **EN / RU** (плюс `other` для остальных).
  Раскладка определяется по активному окну на каждое нажатие.
- Окно статистики:
  - heatmap клавиатуры (белый → красный, `sqrt` для читаемости);
  - подпись клавиши в выбранной раскладке (EN/RU) и число нажатий под ней;
  - топ-10 самых частых клавиш с барами;
  - итоги: всего / сегодня / клавиш в минуту;
  - переключение периода «всё время / сегодня» и вида TKL / полная клавиатура.
- Автосохранение статистики раз в 10 секунд и при выходе.
- Один экземпляр приложения (именованный mutex).
- Поддержка per-monitor DPI, чтобы окна не были мыльными.

## Требования

- Windows 10/11, Python 3.15+ (проект использует `uv`).
- Tkinter входит в стандартную сборку Python с python.org.

## Установка и запуск

```powershell
uv sync
uv run keypress-tracker
```

Без консольного окна (через `gui-scripts`):

```powershell
uv run keypress-tracker-gui
```

Или как модуль:

```powershell
uv run python -m keypress_tracker
```

Полезные флаги:

```powershell
uv run keypress-tracker --debug      # печатать события клавиатуры в консоль
uv run keypress-tracker --reset      # сбросить статистику при запуске
uv run keypress-tracker --data-dir D:\tracker-data
uv run keypress-tracker --version
```

## Управление

| Действие | Как |
| --- | --- |
| Открыть статистику | двойной клик по оверлею, ПКМ → «Статистика…» или `Ctrl+Alt+K` |
| Показать/скрыть оверлей | `Ctrl+Alt+O` или ПКМ → «Скрыть оверлей» |
| Переместить оверлей | зажать ЛКМ и тянуть |
| Сменить раскладку в статистике | кнопки `EN` / `RU` в окне или ПКМ по оверлею |
| Сбросить статистику | ПКМ по оверлею → «Сброс статистики…» |
| Выход | ПКМ по оверлею → «Выход» |

Горячие клавиши работают всегда, пока приложение запущено.

## Где хранятся данные

`%LOCALAPPDATA%\keypress-tracker\`

- `stats.json` — счётчики по раскладкам, общий итог и дневная история
  (хранится 400 дней). Запись атомарная, через `os.replace`.
- `settings.json` — позиция и видимость оверлея, выбранные раскладка/период/вид.
- `stats.json.bak` — резервная копия, если основной JSON оказался повреждён
  (при этом счётчики начинаются заново, файл не удаляется).

## Ограничения

- Приложение видит только то, что проходит через низкоуровневый хук:
  - **не считаются** нажатия в elevated-приложениях и окне UAC, если трекер
    запущен без прав администратора;
  - **не считаются** игры с Raw Input / античит-защитой;
  - смена раскладки по `Win+Space`/`Alt+Shift` учитывается со следующего нажатия.
- Считаются физические нажатия: `Shift+A` — это два нажатия.
- Автоповтор при удержании клавиши не считается (одно нажатие = одно событие).
- Синтетические события (`SendInput`, макросы) игнорируются (`LLKHF_INJECTED`).
- Оверлей не является click-through: он перехватывает клики в своей области.

## Разработка

```powershell
uv sync
uv run python -m unittest discover -s tests -t . -v
```

Структура пакета:

```
src/keypress_tracker/
  win32.py         # ctypes-привязки Win32 (хук, mutex, DPI, layout)
  constants.py     # общие константы и версия
  layouts.py       # геометрия клавиатуры и подписи EN/RU
  heat.py          # интенсивность и цвет heatmap
  store.py         # StatsStore + Settings (JSON, автосохранение)
  capture.py       # поток с WH_KEYBOARD_LL и хоткеи
  overlay.py       # плавающее окно-счётчик
  stats_window.py  # окно статистики и heatmap
  app.py           # связка компонентов и CLI
  __main__.py      # python -m keypress_tracker
tests/             # unittest: store, layouts, heat
```
